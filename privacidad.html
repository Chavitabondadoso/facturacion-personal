Política de privacidad

Última actualización: 30 de septiembre de 2026

Quién usa la aplicación

Facturación personal es una herramienta privada que usa únicamente su autor, con su propia cuenta de Google. No ofrece servicio a otras personas.

Qué datos de Google usa y para qué

  • Gmail: busca los correos del autor que contienen facturas electrónicas (archivos XML/PDF), lee esos archivos adjuntos y añade una etiqueta al correo para no procesarlo dos veces. No envía, borra ni modifica el contenido de ningún correo.
  • Google Drive: crea una carpeta de facturas y guarda en ella los PDF y XML. Solo tiene acceso a los archivos y carpetas que la propia herramienta crea.

Dónde se guardan los datos

Los datos se procesan en la computadora del autor y se guardan únicamente en su propio Google Drive. No se envían a servidores de terceros, no se venden, no se comparten y no se usan con fines publicitarios.

Uso de datos de las API de Google

El uso y la transferencia de la información recibida de las API de Google se apegan a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El autor puede retirar el permiso en cualquier momento desde myaccount.google.com/permissions.
